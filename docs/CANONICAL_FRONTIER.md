# HNK: AFTERWORLD — Canonical Frontier

**Tehkné Solutions**

Current Assets Forge frontier: **AF-001CS — Trade, Barter & Inter-Settlement Economy Runtime**.

AF-001CS extends AF-001CR faction/diplomacy and AF-001CC logistics with contextual valuation, local scarcity/need, barter evaluation, trust/reliability-based credit, explicit trade contracts and route viability derived from margin, distance, risk, relations and escort strength. Trade changes ownership of real resources; it never creates or teleports them.

AF-001CR compatibility remains preserved.

Completion rule remains paired: an AF is complete only after runtime is published in `hnk-rpg-game` and asset/data status is published in `hnk-rpg-game-assets`.
